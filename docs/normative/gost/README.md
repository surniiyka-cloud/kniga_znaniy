# ГОСТ и нормативные документы

Сюда загружайте PDF-файлы ГОСТ, технических регламентов, решений ЕЭК и других нормативных документов, которые нужно использовать при наполнении раздела **1.1**.

## Как загружать

1. Откройте папку `docs/normative/gost/`.
2. Нажмите **Add file → Upload files**.
3. Загрузите PDF без изменения содержания.
4. По возможности называйте файл понятно, например:
   - `GOST_R_8.568-2017.pdf`
   - `RMG_29-2013.pdf`
   - `TR_TS_021-2011.pdf`
   - `EEC_70_2023.pdf`

PDF здесь хранится как исходный нормативный материал. Сам пользовательский интерфейс Книги знаний будет ссылаться на документы из раздела 1.1, а не дублировать ГОСТы в разделе 1.2.
